# CriptoMaster PRO v1 🚀

Painel inteligente e simplificado para monitoramento de Bitcoin em tempo real, focado em investidores iniciantes.

## ✨ Funcionalidades

- **Monitoramento em Tempo Real**: Preços atualizados via API da CoinGecko.
- **Indicação de Momento (O que fazer?)**: Análise automática se é hora de **COMPRAR**, **VENDER** ou **AGUARDAR** baseada na variação das últimas 24h.
- **Notificação Automática via WhatsApp**: Receba alertas diretamente no seu celular quando o preço atingir zonas de oportunidade.
- **Simulador de Lucro Real**: Cálculo considerando as taxas do Mercado Pago para você saber exatamente quanto sobrou no bolso.
- **Conversor Rápido de Satoshis**: Saiba quanto de Bitcoin você compra com qualquer valor em Reais.
- **Interface Responsiva**: Design moderno e otimizado para computadores e celulares (WhatsApp friendly).

## 🛠️ Tecnologias

- **React + TypeScript**
- **Vite** (Build super rápido)
- **Tailwind CSS v4** (Estilização moderna)
- **Lucide React** (Ícones)

## 🚀 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/alex-soares141/Painel-CriptoMaster-PRO-v1.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
